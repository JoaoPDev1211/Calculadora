🧮 Calculadora
Uma calculadora simples desenvolvida com HTML, CSS e JavaScript. Este projeto tem como objetivo fornecer uma ferramenta básica para realizar operações matemáticas fundamentais, servindo também como prática para aprimorar habilidades em desenvolvimento web.

🔧 Funcionalidades
Operações básicas: adição, subtração, multiplicação e divisão.

Interface amigável e responsiva.

Exibição clara dos resultados.
